# Per-screen coverage

Every current category PNG has one row below. A scroll frame is a view of the same screen; its primary action can be outside that frame. No claim that every possible product state was reached. The purpose/action/three-second line is a design interpretation, not a timed human recognition test. Rule citations below govern the corresponding column for every row; failed cells link finding IDs in REPORT.md for exact evidence and recommendation.

P = pass for the visible frame and inspected implementation only; F = a demonstrated failure; U = unverified beyond that scope; N = not applicable. M=P(code)/U(device) means helpers were inspected but motion/native feedback was not observed. A remains U for real screen readers/device hit targets; identified semantic/keyboard problems are recorded as F. A visible-frame pass does not mean full WCAG, Apple or Material conformance. The original rows describe baseline, even though fixes exist in separate PRs.

The color family for all ordinary dark content is white/secondary/muted and applicable labeled semantic accents over background/surface/alt/elevated. PALETTE.md computes each pair, not guessed colors. Inputs additionally use floating crimson; timer buttons use white/crimson; Google uses its approved light surface. Decorative border/track ratios are not text failures. Photographic text is U. Every column refers to the source above (read 2026-10-01). Gold on explicitly marked Pro teasers is a Pro surface, even on a free account.
