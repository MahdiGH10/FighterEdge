## Accessibility detail and limits

Home's visual order is date, identity/checklist, next session/fuel context, Corner Brief, weight and week. Baseline Chrome merged the Nutrition heading with Add food and the brief heading with Unlock; the Settings Health data action absorbed neighboring switches. The new regression tests activate SemanticsAction.tap and verify intended actions/unchanged switch values. This proves the tested semantic boundary behavior, not real VoiceOver/TalkBack pronunciation, navigation or rotor behavior.

AppAccessibility.minTouchTarget is already 48. Shared buttons, header actions, grouped rows and drill chips use it. The strict Flutter target rule is applied instead of claiming WCAG's 24px equals native guidance. Secondary links, filtered chips and conditional controls still need a complete device hit-target sweep. High contrast uses existing text/border helpers; direct color call sites can bypass it. No complete high-contrast conformance claim.

PressScale uses a small scale change and zero duration for reduced animation; PremiumReveal removes movement/stagger in that state; haptic calls name task events. Code review supports these helper behaviors. An instantaneous fixture is not a motion recording. Custom Hero transitions, reaction cue timing, device frame pacing and audible/haptic overlap require a physical test. Text-spacing CSS overrides do not apply to Flutter's canvas text; 200% scaling is not proof of WCAG 1.4.12. Password autofill/paste remain supported; native manager integration and code delivery were not tested.

One-hand judgment from layout: bottom primary setup/auth actions are near the lower viewport after scroll; top Back/plus actions require a reach. This is not a measured thumb test. No new thumb-zone layout was implemented without device evidence.

## Native checks still required

No connected ADB device or installed emulator AVD was available; iOS simulation is unavailable on this Windows host. Native feel and motion were NOT reviewed. Check on a phone: status/navigation bars and contrast; safe areas/cutouts; keyboard and focused-field visibility at 200%; TalkBack/VoiceOver reading order, labels and switch actions; external keyboard/Enter/Space and switch access; reduced-motion transitions and Heroes; haptic intensity and timing; TTS/audio interruptions; launcher/adaptive icon and Android/iOS launch screens; native Google/Apple sheets and password manager; notification permission; one-handed task completion; connected billing/cancellation/restore. No device, permission or tool setting was changed.
